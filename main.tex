\begin{abstract}
Static analyzers are essential in secure software engineering, yet their practical value is constrained by high false-positive rates and costly manual triage. Recent LLM-based triage systems condition on analyzer evidence, but they still rely on uncalibrated confidence and forced binary decisions. This is a poor fit for security workflows: an automated triage system should commit only when the evidence supports a reliable decision, and should defer uncertain alerts rather than silently dismissing potential vulnerabilities.

We introduce \textbf{EVICT} (Evidence-Conditioned Investigation with Calibrated Triage), a framework that casts static-analysis alert triage as cost-sensitive selective prediction. EVICT extracts SARIF-derived evidence, applies schema-guided LLM verification, converts model confidence into calibrated prediction sets, and commits to true-positive or false-positive decisions only when the calibrated set is a singleton. Ambiguous cases are abstained and can be routed to developer review or conditional symbolic escalation. This design separates the statistically calibrated pre-escalation predictor from the post-calibration audit layer, making coverage and deferral explicit.

Our empirical results identify a central bottleneck for LLM-based triage: conformal calibration is only useful when the underlying confidence signal contains meaningful uncertainty information. Reasoning-oriented models and structured prompts produce more informative self-consistency signals than standard one-directional prompting, while code-specialized models can recognize safe code patterns yet remain overconfident. We further show that an \emph{FP-Hunter} prompt, which inverts the default TP-biased prior, increases precision by 13\,pp (38.9\%~$\to$~52.1\%) and reduces ECE by 75\% on a standard lite model---demonstrating that prompt design, not model scale, is the key lever for both calibration and precision. These findings suggest that deployable LLM triage should optimize confidence-signal design, not merely model scale or raw classification accuracy. EVICT provides a principled architecture for this setting: evidence-conditioned reasoning, calibrated abstention, and selective symbolic audit for high-risk uncertainty.
\end{abstract}
