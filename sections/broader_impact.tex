\section{Conclusion and Deployment Impact}
\label{sec:conclusion}

EVICT shows that deployable LLM-based static-analysis triage depends on calibrated abstention, not forced classification. The main empirical lesson is that prompt design, not model scale alone, is the key lever for calibrated selective prediction: on the measured 247-alert Gemini 2.5 Flash Lite prompt comparison, contrastive prompting reduces unanimity to 16.2\% and ECE to 0.337, outperforming a 14B reasoning model's default-prompt confidence diversity.

The deployment benefit is focused developer attention. EVICT should be used as a triage aid that accepts only evidence-supported singleton decisions and returns uncertainty to reviewers. The main risk is over-trust: even calibrated systems can miss vulnerabilities under shift. Practical deployments should retain human review for abstentions, audit high-severity dismissals, avoid sending proprietary code to unapproved APIs, and recalibrate when analyzer, project, or framework distributions change.
